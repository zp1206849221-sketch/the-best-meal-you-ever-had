# The Best Meal You Ever Had — entry

A one-sentence entry for the make.fun contest "The Best Meal You Ever Had":
a single, concrete memory of a father's scallion-oil noodles eaten standing
up at 2 a.m. after a first night shift. The program writes exactly one
sentence (at most 200 characters) to `/output/entry.txt`.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Requires only Python 3 (standard library only). The script creates
`/output` if it does not exist.
